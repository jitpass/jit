# Contributing

The canonical guide is **[CONTRIBUTING.md](../../CONTRIBUTING.md)** at the
repo root: build and test setup, code conventions, and how catalog/docs
drift guards work. Sign-off is via DCO (`git commit -s`); there is no CLA.

Two contributions with a paved path:

- **Adding a tool to the wrap catalog** - one data block plus one
  sanitized fixture, no logic. See [the wrap
  docs](../wrap/index.md#adding-a-tool) and CONTRIBUTING.md.
- **Security findings** - see [Reporting](../security/reporting.md)
  (privately, please).
