## jit agent status

Show whether the agent is running, and whether its session is unlocked

### Synopsis

Reports whether jit agent is running and, if so, whether its session is
unlocked. --format json prints a machine-readable snapshot instead of the
default text summary.

```
jit agent status [flags]
```

### Options

```
      --format string   output format: "text" (default) or "json" (default "text")
```
